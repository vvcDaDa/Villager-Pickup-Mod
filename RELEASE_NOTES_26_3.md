# Villager Pickup 1.4 for Fabric 26.3

This release brings the Fabric edition of Villager Pickup to Minecraft 26.3.

- Requires Minecraft 26.3, Fabric Loader 0.19.5, and Fabric API 0.161.0+26.3.
- Remains server-side; vanilla clients can connect without installing this mod.
- This release contains the Fabric JAR only. NeoForge is not updated for 26.3.
- The JAR is built by GitHub Actions from this release's source commit.
