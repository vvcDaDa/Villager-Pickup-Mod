# Villager Pickup 1.4 for Minecraft 26.3

This release contains separate server-side JARs for Fabric and NeoForge. Download the JAR that matches your server's mod loader; install only one.

| Loader | Release asset | Requirements |
| --- | --- | --- |
| Fabric | `villagerpickup-fabric-26.3-1.4.jar` | Minecraft 26.3, Fabric Loader 0.19.5, Fabric API 0.161.0+26.3, Java 25 |
| NeoForge | `villagerpickup-neoforge-26.3-1.4.jar` | Minecraft 26.3, NeoForge 26.3.0.23-beta or newer, Java 25 |

Vanilla clients can connect without installing the mod. Both JARs are built by GitHub Actions from this release's source commit.

Minecraft 26.3 port: [vvcDaDa](https://github.com/vvcDaDa), assisted by [Codex](https://github.com/codex). Original project authors remain credited in the mod metadata.
