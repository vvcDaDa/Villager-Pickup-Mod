# Villager Pickup 1.4 for NeoForge 26.3

This release brings the NeoForge edition of Villager Pickup to Minecraft 26.3.

- Requires Minecraft 26.3, NeoForge 26.3.0.23-beta or newer, and Java 25.
- Remains server-side; vanilla clients can connect without installing this mod.
- This release contains the NeoForge JAR only. The Fabric 26.3 JAR is available in the [Fabric release](https://github.com/vvcDaDa/Villager-Pickup-Mod/releases/tag/v1.4-fabric-26.3).
- The JAR is built by GitHub Actions from this release's source commit.
